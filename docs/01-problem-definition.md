# 개인 운동 대시보드 문제 정의서

- 작성일: 2026-10-14
- 근거: 대표 본인 인터뷰 (5단계: 사용자 정의 → 병목 파악 → 대상 선정 → 수동/자동 경계 → 핵심 KPI)
- 상태: 인터뷰 확정본. "가정"으로 표시한 항목은 인터뷰에서 직접 확인하지 않은 부분입니다.

---

## 한 줄 문제 정의

> 4년 차 린매스업 중인 사용자가 **운동·식단 기록을 까먹거나 번거로워서 쌓지 못해**, 몸이 목표대로 변하고 있는지 판단할 근거가 없다.
> 이 대시보드는 **입력 부담을 최소화해 기록이 매일 쌓이게 하고**, 쌓인 기록으로 린매스업 진행 상황을 한 화면에서 보여 주는 것을 목표로 한다.

---

## 1. 사용자 정의

| 항목 | 내용 |
|---|---|
| 실사용자 | 대표 본인 1명 |
| 운동 경력 | 4년 차 |
| 운동 패턴 | 헬스(웨이트) 주 3회 이상, 러닝 주 1회 이상 |
| 목표 | 린매스업: 근육량 유지·소폭 증가, 체지방 감량, 체중은 거의 유지 |
| 기대하는 것 | 식단·수면·운동량/변화를 한 곳에서 확인 |
| 현재 도구 | 운동은 Planfit에 가끔 기록, 식단·수면은 기록 없음 |
| 측정 습관 | 체중계 이틀에 1회, 인바디 월 1회 |
| 기기 | 아이폰 (스마트워치·스마트 체중계는 없는 것으로 가정) |
| 확인 빈도 | 매일 |

## 2. 병목 파악

핵심 병목은 **분석이 아니라 기록이 쌓이지 않는 것**이다.

1. **까먹음:** 운동 기록을 "가끔"만 남기는 가장 큰 이유.
2. **식단 입력 장벽:** 저울로 잴 때만 기록이 가능했고, 양·칼로리를 모르는 식사는 기록 자체를 포기하게 됨.
3. **관리 분산:** 운동·식단·체중을 여러 곳에서 따로 관리하는 것이 번거로움.
4. **수면:** 기록 경험 없음.
5. **체성분:** 측정은 꾸준하지만 결과를 모아 두는 곳이 없음.

→ 설계 원칙: **"보기 좋은 화면"보다 "거의 안 드는 입력"이 먼저.**

## 3. 대상 선정 (첫 버전 범위)

| 우선순위 | 대상 | 기록 수준 |
|---|---|---|
| 핵심 1 | 운동 (웨이트) | 운동별 세트·무게·횟수 |
| 핵심 1 | 운동 (러닝) | 운동한 날 기록 (거리·시간 수준으로 가정) |
| 핵심 2 | 식단 | 한 끼 사진이 기본, 그램·칼로리는 알 때만 선택 입력 |
| 보조 | 컨디션 | 피로도·근육통 등 1~5점 간단 체크 |
| 보조 | 체성분 | 체중(이틀 1회), 인바디 골격근량·체지방률(월 1회) 숫자 입력. KPI 판단에 필요하므로 최소 입력 칸 유지 |
| 후순위 | 수면 | 첫 버전 제외. 이후 확장 대상 |

## 4. 수동/자동 경계

원칙: **사람은 사진과 숫자만 넣고, 계산·기억·추정은 시스템이 한다.**

| 구분 | 수동 (사용자) | 자동 (시스템) |
|---|---|---|
| 운동 | 운동 끝나고 한 번에 세트·무게·횟수 입력 (대시보드에서 직접 입력, Planfit 연동 안 함) | 지난번 같은 운동의 무게·횟수 미리 채우기, 볼륨 계산 |
| 식단 | 한 끼 사진 업로드, 알면 그램·칼로리 입력 | AI가 메뉴·칼로리·단백질 추정 ("추정치"로 표시, 사용자가 수정 가능) |
| 컨디션 | 1~5점 탭 몇 번 | 운동 기록과 같은 날짜에 나란히 표시 |
| 체성분 | 체중·인바디 수치 입력 | 추세선 계산 |
| 기록 유도 | 없음 | 운동 후·식사 시간 알림 (아이폰) |

## 5. 핵심 KPI

매일 보는 대시보드이므로 KPI를 보는 주기별로 나눈다.

| 주기 | KPI | 정의 | 왜 필요한가 |
|---|---|---|---|
| 매일/주간 | **기록률** | 이번 주 운동 기록 횟수, 식사 사진 끼 수 | 병목(기록 안 쌓임)을 직접 측정. 다른 KPI의 전제 조건 |
| 월간 | **인바디 골격근량** | 유지 또는 증가 | 린매스업 결과 지표 (근육) |
| 월간 | **인바디 체지방률** | 감소 | 린매스업 결과 지표 (지방) |

> 벤치프레스 최고 무게는 1RM을 매번 재는 것이 아니어서 KPI에서 뺐습니다 (3차 인터뷰에서 결정). "지난번보다 더 하기"는 운동 화면의 최근 5회 흐름으로 확인합니다.

**성공의 정의:** 기록률이 유지되는 상태에서, 월별 인바디에서 골격근량은 유지·증가, 체지방률은 감소한다.

## 기본값으로 둔 항목 (구현 단계에서 조정 가능)

1. **기록률 목표치:** 운동 주 4회(헬스 3 + 러닝 1), 식사 사진 하루 2끼 이상.
2. **컨디션 체크 항목:** 2차에서 확정. 아침은 피로도·수면 질, 운동 후는 운동 강도 느낌·집중도.
3. **알림 시간:** 식사 알림 시간대와 운동 후 알림 방식은 구현 시 설정.
4. **러닝 기록 항목:** 거리·시간 (페이스는 자동 계산). → 6차 검수에서 변경: 거리·평균 페이스를 적고 시간은 자동 계산 ([06-build.md](./06-build.md) 4장).
