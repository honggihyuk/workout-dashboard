## 1. 업무 흐름 정의

하루 동안 언제, 무엇을, 어떤 순서로 하는지입니다.

### 운동하는 날

| 시점 | 하는 일 | 대시보드에서 보는 것 |
|---|---|---|
| 아침 | 하루 컨디션 체크 (피로도·수면 질) | 오늘 루틴 진행 상황 |
| 아침·점심·저녁 식사 | 끼니마다 사진 올리기 → AI 추정 확인 | |
| 하루 중 | 영양제 먹었는지 체크 (시간까지) | |
| 저녁, 운동 전 | | 지난번 같은 운동의 무게·횟수 → "지난번보다 더 하기" 목표 |
| 저녁, 운동 후 | 세트·무게·횟수 한 번에 입력 → 운동 컨디션 체크 (강도 느낌·집중도) → 보충제·쉐이크 체크 | 오늘 기록과 지난번 비교 |
| 운동 직후 (이틀에 한 번) | 체중 측정·입력 | |
| 월 1회 | 인바디 결과 입력 | 지난달 대비 변화 |

### 쉬는 날

운동하는 날과 같고, **운동 기록·운동 후 컨디션·보충제·쉐이크만 빠집니다.**

### 대시보드를 보는 두 가지 목적

1. **운동 전 비교:** 지난번에 얼마나 했는지 보고 오늘 더 하기 위해.
2. **평소 루틴 확인:** 건강을 위한 루틴(식사·영양제·운동)이 잘 지켜지고 있는지.

## 2. 데이터 정의

기록장에 만들 칸입니다.

### 2-1. 고정 목록 (처음 한 번 등록, 가끔 수정)

| 목록 | 칸 | 초기 값 |
|---|---|---|
| 내 운동 목록 | 운동명, 헬스/러닝 구분 | 벤치프레스 등 (사용자가 등록) |
| 내 영양제·보충제 목록 | 이름, 구분(매일 / 운동하는 날만) | 아래 표 |

| 이름 | 구분 |
|---|---|
| 비타민C | 매일 |
| 루테인 | 매일 |
| rTG 오메가3 | 매일 |
| 칼슘·마그네슘·비타민D·아연·망간 (한 알) | 매일 |
| 프로바이오틱스 | 매일 |
| 크레아틴 | 운동하는 날만 |
| EAA | 운동하는 날만 |
| 글루타민 | 운동하는 날만 |
| WPI 쉐이크 | 헬스하는 날 (러닝만 한 날은 선택) |

### 2-2. 매일 쌓이는 기록

| 기록장 | 칸 | 비고 |
|---|---|---|
| **운동 기록** | 날짜, 운동명, 세트별 무게(kg)·횟수, 메모 | 웜업·본세트 구분 없음. 지난번 같은 운동 값을 미리 채움 |
| **러닝 기록** | 날짜, 거리, 시간, 메모 | 페이스는 자동 계산. 6차에서 입력을 거리·평균 페이스로 바꾸고 시간을 자동 계산 |
| **식사 기록** | 날짜, 끼니(아침·점심·저녁·간식), 시간, 사진, AI 추정(메뉴·칼로리·단백질), 직접 입력(그램·칼로리, 선택), 메모 | |
| **영양제·보충제 체크** | 날짜, 항목명, 먹음 여부, 먹은 시간 | 양은 기록하지 않음 |
| **아침 컨디션** | 날짜, 피로도(1~5), 수면 질(1~5) | |
| **운동 후 컨디션** | 날짜, 운동 강도 느낌(1~5), 집중도(1~5) | |
| **체중** | 날짜, 체중(kg) | 이틀에 한 번, 운동 직후 |
| **인바디** | 날짜, 골격근량, 체지방률, 체지방량, 기초대사량 | 월 1회 |

### 2-3. 시스템이 계산하는 값

| 값 | 계산 방법 |
|---|---|
| 운동 볼륨 | 세트별 무게 × 횟수의 합 |
| 기록률 (주간) | 이번 주 운동 기록 횟수, 식사 사진 끼 수 |
| 러닝 페이스 | 시간 ÷ 거리 (6차부터는 입력값이고, 시간 = 거리 × 페이스) |
| 체성분 추세 | 체중·인바디 값의 변화 흐름 |
| 단백질 목표 (6차 추가) | 그날(없으면 그 전 마지막) 체중 × 1.5~2g. 먹은 단백질(끼니 + 먹은 쉐이크)과의 차이 |
| 운동 칼로리 (6차 추가) | 러닝: 체중 × 거리(km). 헬스: (MET − 1) × 체중 × 세트 수 × 3분 |
| 하루 쓴 칼로리 (6차 추가) | 기초대사량(인바디, 없으면 체중 × 24) × 1.2 + 운동 칼로리. 먹은 칼로리와 비교 |

## 3. 상태 정의

각 기록이나 하루가 지금 어느 단계인지입니다. 대시보드에서 색이나 표시로 보입니다.

### 3-1. 운동하는 날 판단

**그날 운동 기록(헬스 또는 러닝)이 하나라도 있으면 "운동하는 날"**, 없으면 "쉬는 날"입니다. 요일을 미리 정하지 않습니다.

- 러닝만 한 날도 운동하는 날입니다. 보충제(크레아틴·EAA·글루타민)는 체크 대상이고, 쉐이크는 **선택**입니다. 먹으면 체크하고, 안 먹어도 루틴 완료에 영향이 없습니다.
- 운동을 기록하지 않은 날은 쉬는 날로 처리되므로, 운동을 빼먹은 것은 하루 루틴이 아니라 **주간 기록률(운동 주 4회 목표)**에서 드러납니다.

### 3-2. 하루 루틴

| 상태 | 조건 |
|---|---|
| 진행 중 | 오늘이 아직 끝나지 않았고 완료 조건을 다 채우지 않음 |
| 완료 | 아래 완료 조건을 모두 채움 |
| 놓친 항목 있음 | 하루가 끝났는데 완료 조건이 남아 있음 |

**완료 조건**
- 모든 날: 아침 컨디션 + 식사 사진 3끼 + 매일 먹는 영양제 체크
- 운동하는 날 추가: 운동 기록 + 운동 후 컨디션 + 보충제 체크 + 쉐이크 체크 (헬스한 날만. 러닝만 한 날은 선택)

**나중에 채우기:** 깜빡한 날도 다음 날 이후에 기록을 채울 수 있고, 조건을 다 채우면 "놓친 항목 있음"에서 "완료"로 바뀝니다.

- 가정: 하루의 끝은 자정입니다.
- 체중(이틀에 한 번)과 인바디(월 1회)는 하루 루틴 완료 조건에 넣지 않았습니다.

### 3-3. 식사 기록

```
미기록 → 사진 올림 → AI 추정 완료 → 확인함
```

| 상태 | 뜻 |
|---|---|
| 미기록 | 해당 끼니에 아무것도 없음 |
| 사진 올림 | 사진은 있고 AI가 분석하는 중 |
| AI 추정 완료 | 메뉴·칼로리·단백질 추정치가 나옴 (아직 사용자가 확인하지 않음) |
| 확인함 | 사용자가 추정치를 보고 맞다고 하거나 고친 뒤 확정함 |

- 하루 루틴의 "식사 사진 3끼"는 사진만 올라가면 채운 것으로 봅니다 (가정).

### 3-4. 영양제·보충제

| 상태 | 뜻 |
|---|---|
| 안 먹음 | 아직 체크하지 않음 |
| 먹음 | 체크함 (먹은 시간 기록) |
| 해당 없음 | 쉬는 날의 보충제·쉐이크 |
| 선택 | 러닝만 한 날의 쉐이크. 먹으면 체크하고, 안 먹어도 루틴 완료에 영향 없음 |

### 3-5. 운동

| 상태 | 뜻 |
|---|---|
| 운동 전 | 오늘 운동 기록이 아직 없음. 지난번 같은 운동 기록을 보여 줌 |
| 기록 완료 | 오늘 운동 기록이 입력됨 → 운동하는 날로 바뀜 |

### 3-6. KPI 표시

| 대상 | 상태 | 비교 기준 |
|---|---|---|
| 인바디 골격근량 | 좋음(유지·증가) / 주의(감소) | 지난달 |
| 인바디 체지방률 | 좋음(감소) / 주의(유지·증가) | 지난달 |
| 주간 기록률 | 목표 달성 / 미달 | 운동 주 4회, 식사 사진 하루 2끼 이상 (1차 기본값) |

> 참고: 1차 기록률 기본값은 "식사 사진 하루 2끼 이상"이고, 이번 하루 루틴 완료 조건은 "3끼"입니다. 루틴 완료는 매일의 이상적인 목표, 기록률은 주간 최소 기준으로 구분해 두었습니다.
