## 1. 프레임 목업

색과 글꼴을 빼고 **화면 구성과 흐름만** 보는 회색 목업입니다. 색·글꼴·아이콘은 3단계 테마 선택에서 정합니다.

- 목업 링크: https://claude.ai/artifact/X6dB4EtbWY27tNTiaC6rWK (항상 최신 버전)
- 원본 파일: [v1](./mockups/frame-v1/), [v2](./mockups/frame-v2/)
- 크기: 아이폰 화면 너비 390px 기준. Play로 열면 탭과 버튼으로 화면끼리 이동합니다.

### v2: 운동 흐름 다시 설계 (2026-10-14)

v1 피드백: "헬스 운동은 종류가 워낙 많은데, Planfit 앱을 참고해서 비효율적인 목업을 수정해 달라."

v1의 운동 화면은 운동 4개를 버튼으로 나열하고 "+ 운동 추가"만 있어서, 운동 종류가 많아지면 고르기도 기록하기도 느립니다. Planfit 앱스토어 소개(루틴 추천·직접 만든 루틴, 무게·횟수·세트 기록, 운동 일지·캘린더, 헬스장 기구 기준 추천)와 운동 기록 앱들의 공통 화면 구조를 참고해 아래처럼 바꿨습니다. 앱 내부를 직접 열어 본 것은 아닙니다.

| 바꾼 점 | v1 | v2 |
|---|---|---|
| 운동 시작 | 빈 기록 화면 | **내 루틴으로 시작**(다음 차례 표시), 지난 운동 그대로, 운동 골라서 시작 |
| 운동 고르기 | 운동 4개 버튼 | **검색 + 부위 탭(가슴·등·하체·어깨·팔·복근·유산소) + 기구 필터(바벨·덤벨·머신·케이블·맨몸)**, 최근 한 운동, 여러 개 한 번에 고르기, 새 운동 만들기 |
| 세트 기록 | 무게·횟수 칸 | 세트마다 **지난번 값 옆에 표시 + 칸에 미리 채움**, 세트 +/−, 운동 메뉴(순서 바꾸기·바꾸기·빼기) |
| 루틴 | 없음 | **루틴 편집**: 이름, 운동 순서, 운동별 세트 수. 무게·횟수는 지난번 값을 씀 |
| 운동별 기록 | 운동 화면 안 | 별도 화면(최근 5회 흐름)으로 분리 |
| 오늘 화면 | 버튼 2개 | "운동 기록하기" 하나 + 다음 차례 루틴 표시 |
| 설정 | 운동 목록 | 내 루틴, 운동 목록(기본 운동 + 내가 만든 운동, 숨기기) |

- 기본 운동 목록은 직접 만든 목록(자주 쓰는 헬스 운동 100여 개 예정)을 씁니다. 다른 앱의 운동 데이터를 그대로 가져오지 않습니다.
- 데이터 표 추가(4차 문서 2-1): `routines`, `routine_items`, `exercises`에 부위·기구·직접 만든 운동·숨기기 칸.

## 2. UI 의사결정

화면 전체에 적용할 규칙과, 프레임 목업에서 제안만 해 둔 것(P1~P5)을 정합니다. **추천**은 대표님이 바꾸지 않으면 그대로 갑니다.

### 확정 (2026-10-14, 전부 추천대로)

| 번호 | 정할 것 | 추천 | 다른 선택 | 이유 |
|---|---|---|---|---|
| U1 (P1) | 체중 입력 위치 | 운동 기록 화면 아래 칸 + 몸 변화 화면 | 몸 변화 화면에서만 | 운동 직후에 재니까 기록하는 김에 입력 |
| U2 (P2) | 식단 오늘 합계 | 표시 (확인한 끼니의 칼로리·단백질) | 표시 안 함 | 하루 식단을 한 줄로 확인 |
| U3 (P3) | 영양제 체크 | 하나씩 + **"매일 영양제 모두 먹음" 버튼** | 하나씩만 | 5종을 보통 같이 먹으니 한 번에 체크 (v1 목업 제안에서 바꿈) |
| U4 (P4) | 간식 칸 | 선택 (루틴 완료에 안 들어감) | 필수 | 2차 완료 조건이 식사 3끼 |
| U5 (P5) | 운동별 기록 그래프 | 볼륨(무게×횟수 합) 막대 | 세트 최고 무게 선 | 1RM을 재지 않으므로 볼륨이 변화를 더 잘 보여 줌 |
| U6 | 무게·횟수 입력 | 지난번 값으로 미리 채운 칸 + 숫자 키패드 | 칸마다 +/− 버튼 | 달라진 칸만 고치면 되고 화면이 덜 복잡함 |
| U7 | 저장 | 입력하는 동안 폰에 자동 임시 저장, "저장" 버튼으로 확정 | 버튼으로만 저장 | 앱이 닫혀도 입력이 남음 (4차 안정성 대비) |
| U8 | 삭제 | 지운 뒤 몇 초간 "되돌리기" 표시 | 매번 확인 창 | 실수는 되돌리고, 평소엔 한 번에 끝 |
| U9 | 식사 사진 올리기 | 누르면 카메라·앨범 중 고르기 | 카메라 바로 열기 | 먹은 뒤 앨범 사진을 올리는 경우도 있음 |
| U10 | 앱 첫 화면 | 항상 "오늘" 탭 | 마지막으로 본 화면 | 매일 루틴 확인이 주목적 |
| U11 | 글자 크기 | 아이폰 글자 크기 설정을 따름 | 앱 고정 크기 | 읽기 편한 크기를 기기에서 한 번에 조절 |

## 3. 테마 선택

색, 글꼴, 아이콘 모양, 밝은/어두운 화면을 정합니다. 후보와 확정 테마는 목업의 **"테마 후보" 페이지**에 오늘 화면으로 그려 두었습니다 (원본: [theme-v1](./mockups/theme-v1/), [theme-final](./mockups/theme-final/)).

### 확정 테마 (2026-10-14)

**B의 모양·글꼴 + 밝은 모드는 A 색, 어두운 모드는 B 색.** 아이폰 설정(밝게/어둡게)에 따라 자동으로 바뀝니다. 코드는 [src/styles.css](../src/styles.css)에 반영했습니다.

| 항목 | 밝은 모드 (A 색) | 어두운 모드 (B 색) |
|---|---|---|
| 바탕 | #F6F6F4 | #0F1115 |
| 카드 | #FFFFFF | #1A1D23 |
| 테두리·막대 빈칸 | #E4E4E0 | #2A2E36 |
| 글자 | #141414 | #F2F3F5 |
| 보조 글자 | #5C5C5C | #A3A8B3 |
| 강조색 (버튼·진행 막대·선택된 탭) | 파랑 #2F5BEA, 위 글자 흰색 | 라임 #C6F432, 위 글자 검정 |
| 강조 바탕 ("좋음" 표시 등) | #E8EEFD | #2A3312 |
| 주의 색 / 주의 바탕 | #B23A0A / #FDEEE6 | 주황 #FF9F43 / #3A2A17 |
| 체크 안 한 칸 테두리 | #C9C9C4 | #4A505B |
| 아래 탭 바탕 | #FFFFFF | #15181D |

| 공통 | 값 |
|---|---|
| 글꼴 | Gothic A1 (400·600·800), 없으면 아이폰 기본 글꼴 |
| 숫자 | 굵게(800), 크게 |
| 모서리 | 카드 14px, 버튼·입력칸 12px, 작은 칩 8px |
| 탭 아이콘 | 선으로 그린 아이콘 (선 굵기 2.2), 선택된 탭은 강조색 + 굵은 글자 |
| 글자 크기 | 아이폰 설정을 따름 (U11) |

- 밝은 모드 강조색이 라임이 아니라 파랑인 이유: 흰 바탕 위 라임은 글자·막대가 잘 안 보입니다 (대비 1.3:1). A 색을 쓰기로 한 결정에 맞춰 파랑을 썼습니다.
- 글자와 바탕의 대비는 두 모드 모두 4.5:1 이상입니다.

### 후보 v1 (2026-10-14)

| 후보 | 느낌 | 바탕 / 카드 | 강조색 | 주의 색 | 글꼴 | 모서리 |
|---|---|---|---|---|---|---|
| A 화이트 미니멀 | 깔끔한 기본 앱 느낌 | #F6F6F4 / #FFFFFF | 파랑 #2F5BEA | #B23A0A | IBM Plex Sans KR | 16px |
| B 다크 스포츠 | 헬스장 앱 느낌, 숫자를 크게 | #0F1115 / #1A1D23 | 라임 #C6F432 | 주황 #FF9F43 | Gothic A1 (굵게) | 8~14px |
| C 차분한 그린 | 부드럽고 편안한 건강 앱 느낌 | #F3F1EC / #FFFFFF | 초록 #1F6F54 | #9A4412 | Noto Sans KR | 20px, 둥근 버튼 |

- 공통: 탭 아이콘은 선으로 그린 아이콘(오늘·운동·식단·몸 변화·설정), 글자와 바탕의 대비는 읽기 기준(4.5:1 이상)을 맞췄습니다.
- "좋음"과 "주의"는 색뿐 아니라 밝기도 달라서 색 구분이 어려워도 알아볼 수 있게 했습니다.
