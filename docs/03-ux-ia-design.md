## 1. 정보구조 설계

### 1-1. 기기

- **아이폰 화면 기준**으로 설계합니다.
- PC에서는 같은 화면이 넓게 열리는 정도로만 지원하고, PC 전용 화면은 따로 만들지 않습니다.

### 1-2. 메뉴 구조

화면 아래에 탭 5개가 있습니다.

```
앱
├─ 오늘
│   ├─ 이번 주 KPI 요약 (맨 위)
│   ├─ 오늘 루틴 체크리스트
│   │   ├─ 아침 컨디션 (피로도·수면 질)
│   │   ├─ 식사 3끼 (식단 화면으로 이동)
│   │   ├─ 영양제 체크 (매일 5종)
│   │   ├─ 보충제·쉐이크 체크 (운동하는 날)
│   │   └─ 운동 (운동 화면으로 이동)
│   └─ 날짜 → 달력
│       └─ 날짜별 기록 보기 / 빠진 기록 채우기
├─ 운동
│   ├─ 운동 전: 최근 5회 흐름 보기
│   ├─ 운동 후: 세트·무게·횟수 입력, 러닝 입력, 메모
│   └─ 운동 후 컨디션 (강도 느낌·집중도)
├─ 식단
│   ├─ 끼니별 사진 올리기 (아침·점심·저녁·간식)
│   ├─ AI 추정 확인·수정
│   └─ 직접 입력 (그램·칼로리), 메모
├─ 몸 변화
│   ├─ 체중 입력·추세
│   ├─ 인바디 입력·추세 (골격근량·체지방률·체지방량·기초대사량)
│   └─ 컨디션 추이
└─ 설정
    ├─ 운동 목록
    ├─ 영양제·보충제 목록
    └─ 알림 시간
```

### 1-3. 배치 결정

| 항목 | 위치 | 이유 |
|---|---|---|
| 영양제·보충제 체크 | 오늘 탭 | 하루 루틴과 함께 보기 때문 |
| 달력 | 오늘 탭 위쪽 날짜를 누르면 열림 (기본값) | 오늘 루틴과 지난 날 루틴을 같은 흐름으로 보기 위해 |
| 빠진 기록 알림 | 달력에만 표시 | 오늘 화면에는 따로 알림을 띄우지 않음 |

## 2. 화면별 핵심 목표

| 화면 | 핵심 목표 | 결정 사항 |
|---|---|---|
| 오늘 | 남은 할 일을 한눈에 보고 바로 체크하기 | 맨 위는 **이번 주 KPI**, 그 아래 체크리스트 |
| 운동 (전) | 지난 기록을 보고 오늘 목표 정하기 | 같은 운동의 **최근 5회 흐름** (횟수는 기본값) |
| 운동 (후) | 기록 입력을 빠르게 끝내기 | 지난번 무게·횟수를 미리 채워 둠 |
| 식단 | 사진 한 장으로 끼니 기록 끝내기 | AI 추정은 사용자가 "확인함"으로 확정 |
| 몸 변화 | 린매스업이 잘 되고 있는지 판단하기 | 기본 기간 **1개월** |
| 달력 | 루틴이 지켜진 패턴 보기, 빠진 기록 채우기 | 날짜별 상태를 색으로 표시 |
| 설정 | 목록과 알림 관리하기 | 영양제·보충제 9종은 처음부터 등록해 둠 (기본값) |

### 오늘 화면 배치 예시

```
┌──────────────────────────────┐
│  10월 14일 (화)  ▼  ← 누르면 달력 │
├──────────────────────────────┤
│  이번 주 KPI                    │
│  운동 3/4회 · 식사 사진 12끼      │
│  인바디: 골격근량 좋음 · 체지방률 좋음 │
├──────────────────────────────┤
│  오늘 루틴                       │
│  ☑ 아침 컨디션                   │
│  ☐ 식사  아침 ☑ 점심 ☑ 저녁 ☐     │
│  ☐ 영양제 5종 중 3                │
│  ☐ 보충제·쉐이크 (운동하는 날)      │
│  ☐ 운동  [운동 기록하기]           │
└──────────────────────────────┘
 [오늘] [운동] [식단] [몸 변화] [설정]
```

## 3. 상태별 화면 설계

2차 분석서에서 정한 상태마다 화면이 어떻게 보이는지입니다. 표시는 모두 **조용한 표시**(색, 작은 배지, 문구)로 하고, 애니메이션 같은 축하 연출은 넣지 않습니다.

### 3-1. 오늘 화면

| 상태 | 화면 |
|---|---|
| 진행 중 | 남은 할 일을 강조하고, 끝낸 항목은 체크 표시 |
| 완료 | 체크리스트 위에 "오늘 루틴 완료" 표시 |
| 운동 기록 전 | 운동 칸에 "운동 기록하기" 버튼. 보충제·쉐이크 칸은 "운동하는 날" 표시와 함께 항상 보임 |
| 운동 기록 후 | 운동 칸 체크, 보충제·쉐이크가 루틴 완료 조건에 들어감 |
| 러닝만 한 날 | 쉐이크 칸에 "선택" 표시. 체크하지 않아도 루틴 완료 가능 |
| 쉬는 날 (운동 기록 없이 하루가 끝남) | 보충제·쉐이크는 루틴 완료 조건에서 빠짐 |

- 보충제는 운동 전에 먹을 수 있으므로 **언제든 체크 가능**하고, 운동을 기록한 날만 루틴에 반영합니다.
- 어제 빠진 기록이 있어도 오늘 화면에는 알림을 띄우지 않습니다. 달력에서만 보입니다.

### 3-2. 운동 화면

| 상태 | 화면 |
|---|---|
| 운동 전, 기록 있음 | 같은 운동의 최근 5회 무게·횟수 흐름 |
| 운동 전, 처음 하는 운동 | "첫 기록입니다" 안내, 빈 입력 칸 |
| 입력 중 | 지난번 무게·횟수가 미리 채워진 칸 |
| 저장 완료 | 오늘 기록 요약과 지난번 대비 |

### 3-3. 식단 화면

끼니(아침·점심·저녁·간식)마다 아래 상태를 가집니다.

| 상태 | 화면 |
|---|---|
| 미기록 | 빈 칸과 사진 올리기 버튼 |
| 분석 중 | 사진과 "분석 중" 표시 |
| 확인 필요 (AI 추정 완료) | 추정 메뉴·칼로리·단백질과 "확인 필요" 배지, [확인함] 버튼 |
| 확인함 | 확정된 메뉴·칼로리·단백질 |
| 분석 실패 | **사진은 저장**되고, **직접 입력 칸이 바로 열림** |

- 분석 실패 후 직접 입력하지 않아도 사진이 저장됐으므로 하루 루틴의 식사 칸은 채워집니다 (2차 가정과 같음).

### 3-4. 몸 변화 화면

| 상태 | 화면 |
|---|---|
| 좋음 | 초록색 (골격근량 유지·증가, 체지방률 감소) |
| 주의 | 주황색 (골격근량 감소, 체지방률 유지·증가) |
| 비교할 기록 없음 | 인바디가 1회뿐이면 "비교할 기록이 아직 없음" |
| 기간 | 기본 1개월, 바꿔서 볼 수 있음 |

### 3-5. 달력 화면

| 날짜 상태 | 표시 |
|---|---|
| 완료 | 완료 색 |
| 놓친 항목 있음 | 주의 색, 누르면 빠진 항목을 보고 바로 채울 수 있음 |
| 기록 없음 | 빈 날짜 |
| 오늘 | 진행 중 표시 |
| 미래 | 흐리게 |

### 3-6. 처음 사용할 때

| 상태 | 화면 |
|---|---|
| 기록이 하나도 없음 | 오늘 화면의 KPI 자리에 "기록이 쌓이면 여기에 이번 주 요약이 보입니다" 안내 (기본값) |
| 운동 목록 없음 | 운동 화면에서 운동을 처음 입력할 때 목록에 자동 추가 (기본값) |
| 영양제·보충제 목록 | 2차에서 정한 9종이 미리 등록되어 있음 (기본값) |
